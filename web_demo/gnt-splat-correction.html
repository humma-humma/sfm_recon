15fps GNT with corrected splat gap frames

Six-second outdoor turn, 960 × 540, 30fps. All candidates keep the same 90 GNT anchors. Only intermediate frames change. No new GNT rendering or splat training.

Colour and detail corrections use only the neighbouring even-numbered GNT anchors. Withheld odd GNT views are used only for scoring. The fallback variant blends with the existing motion interpolation where splat flow is unreliable; it is not a pure splat render.

Gap-only results and limitations

Scores compare 89 intervening frames (1–177) with GNT, not ground-truth photos. Higher PSNR/SSIM is better. Lower temporal residual means less change in the error relative to genuine GNT; it is not a perceptual smoothness guarantee. Final frame 179 has no future anchor and is scored separately in results.json. The fixed splat model already trained on some views here. Indoor and dynamic scenes remain untested.
